# Launch

## The asset that matters

A 30-second screen recording. No voiceover, no talking head, no feature list. Just the
cursor moving across effect after effect, cut tight to music. This is a visual product —
the video *is* the pitch, and it is the only piece of marketing worth real effort.

Recording notes:
- 60fps, retina, cursor visible
- One effect per ~2.5 seconds, sequenced from quiet to loud, best effect last
- Show the release/settle, not just the trigger. That is the part that looks expensive
- End on the install command, held on screen for three full seconds

## Landing page

One page. Hero is a live effect the visitor triggers by accident while reading — the page
demonstrates itself. Gallery below, grouped by buttons / cards / text. Each tile: live
preview, code tab, copy-install button. No sidebar, no search, no docs framework.

Copy rules: say what it does, not how it feels. "Hover effects for React and Tailwind.
Copy, paste, no dependencies." Then the install command. Nothing about "elevate your UI".

Include one line about what HoverUI is *for* — landing pages and marketing surfaces, not
high-frequency app chrome. Design engineers notice that distinction and it buys you
credibility that no amount of polish will.

## Channels, launch day

1. X — video first, install command in the post, not a reply
2. `r/webdev`, `r/nextjs`, `r/reactjs` — video, and answer every comment for six hours
3. PR to `awesome-shadcn-ui`
4. Peerlist launch
5. Post in the shadcn Discord's showcase channel
6. PR to the shadcn registry directory for the `@hoverui` namespace

Skip Product Hunt on day one. Save it for when there are ~25 effects and a reason to
return.

## After launch: the cadence is the product

One new effect per week, posted as a standalone clip. This is the entire growth strategy.
It works because:

- Each clip is a fresh piece of content with near-zero marginal cost
- The 90-minute build rule means one week's work is one evening
- A registry that visibly grows earns a bookmark; a static one does not

Set a recurring reminder. Missing two weeks in a row is the failure mode, not building
the wrong effect.

## What not to do after launch

- Do not start a Pro tier because the traffic looked good
- Do not add vertical categories because someone asked for "marketing sections"
- Do not port to Vue because one comment asked
- Do not rewrite the site with a docs framework

Add effects. That is the only move for the first three months.
