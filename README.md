# HoverUI

Hover effects for React and Tailwind. Copy, paste, no dependencies.

```bash
npx shadcn@latest add https://hoverui.com/r/magnetic-button.json
```

Built for landing pages, portfolios, and marketing surfaces — the places a visitor
arrives once and should remember. Deliberately not built for high-frequency app chrome,
where the right amount of hover animation is usually none.

Every effect is a single file with no runtime dependencies, and every effect handles
keyboard focus, touch resting states, and `prefers-reduced-motion` correctly.
